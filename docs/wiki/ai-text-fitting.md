# Подгонка текста через ИИ

ИИ нужен не для творческого рерайта, а для технической задачи: сделать текст достаточно коротким для Telegram и сохранить смысл исходного текста из Битрикс.

## Ограничения

Для обычного текстового сообщения целевой лимит - 4096 символов после парсинга сущностей.

Для caption у фото или альбома целевой лимит - 1024 символа после парсинга сущностей.

Нужно оставлять запас, например 3900 для текста и 950 для caption, чтобы избежать ошибок из-за ссылок, HTML-сущностей или будущих служебных добавок.

## Правила поведения ИИ

ИИ должен:

- сохранить факты, даты, названия, цены, адреса и ссылки;
- не добавлять новых фактов;
- не менять тон сильнее, чем нужно для сокращения;
- не придумывать заголовки, если они не нужны;
- возвращать только финальный текст без объяснений;
- укорачивать текст только если он не проходит лимит.

Если исходный текст уже помещается в лимит, сервис должен отправлять его без вызова ИИ. Это снизит стоимость, задержку и риск нежелательного изменения текста.

## Детерминированная страховка

После ответа ИИ сервис обязан снова проверить длину. Если текст все еще слишком длинный, нужно применить безопасную детерминированную обрезку по границе предложения или слова и добавить короткий маркер, например `...`.

## Исходный текст

Точное правило сборки текста нужно подтвердить. Возможные варианты:

- `name` как заголовок, затем `preview_text`;
- `name`, `preview_text` и `detail_text`;
- только `preview_text`;
- отдельный шаблон с ссылкой на сайт или без ссылки.
